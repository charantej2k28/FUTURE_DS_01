# Business Sales Performance Analytics

## Project Overview
This project analyzes business sales data to identify revenue trends, profitable categories, top-performing products, and regional performance.

## Tools Used
- Power BI
- Excel
- GitHub

## KPIs Analyzed
- Total Sales
- Total Profit
- Total Orders
- Sales Trend
- Category Performance
- Regional Performance

## Key Insights
1. Technology category generated highest profit.
2. West region showed strongest sales performance.
3. Sales increased during year-end months.
4. Furniture category had lower profit margins.

## Recommendations
1. Focus marketing on profitable categories.
2. Improve low-profit products.
3. Expand business in high-performing regions.
4. Optimize discount strategies.
